# AI Study Assistant

An AI-powered desktop study assistant built using Python, Tkinter, and Groq API.

## Features

- Ask AI study questions
- Summarize notes
- Generate quizzes
- Explain difficult topics simply
- Voice input
- Text-to-speech
- Save study history
- Interactive GUI

## Technologies Used

- Python
- Tkinter
- Groq API
- SQLite
- SpeechRecognition
- gTTS

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python main.py
```
